Path C — avio-dev WebRTC preview

Standalone validation harness for the Path C pipeline: avio-capture (Swift) → ffmpeg muxer → go2rtc avio-dev stream → this page. Use side-by-side with the production dashboard's avio stream (http://localhost:3000/#dallas/faculty-podcast) to A/B compare latency, quality, and motion smoothness.

Prerequisites: the Path C swift+ffmpeg pipeline must be running. Start it by POSTing to the sidecar's /avio/probe-swift-pipeline endpoint, e.g.
curl -X POST 'http://127.0.0.1:3301/avio/probe-swift-pipeline?duration=120'
